# Write openbnet in Rust

The server parses untrusted binary packets from many long-lived connections, and PvPGN does this in C++ with manual memory management. We chose Rust for memory safety without garbage collection pauses, exhaustive handling of packet types, and a single deployable binary.

## Considered Options

- **Go**: quicker to write, easier for casual contributors, and fast enough.
- **Modern C++**: easiest to port from PvPGN, but keeps the memory-safety problem.
